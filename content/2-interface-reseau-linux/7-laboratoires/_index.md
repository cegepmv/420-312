Les laboratoires suivants ont pour objectif de mettre en pratique la gestion des interfaces réseau Linux et de faire le lien entre :

+ les **interfaces réseau** ;
+ les **adresses MAC et IP**;
+ les **routes** ;
+ **ARP** ;
+ La commande `ip` ;
+ `NetworkManager` et `nmcli` ;
+ **Netplan** ;
+ les différents modes d'adaptateurs VMware.

3 machines virtuelles sont fournies :

|VM|	Système de configuration|
|--|---------------------------|
|`rocky-10.2.ova`|	NetworkManager / `nmcli`|
|`ubuntu-server-26.04.ova`|	Netplan|
|`ubuntu-desktop-26.04.ova`|NetworkManager / `nmcli`|

Les trois machines disposent initialement d'une interface réseau permettant leur accès au réseau utilisé pour le laboratoire.
